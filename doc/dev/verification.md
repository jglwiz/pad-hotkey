# 验证摘要

以下是历史验证结果，不代表每次文档变更都重新运行了硬件测试。个人配置和完整本机调试记录保存在 Git 忽略的 private/，不随仓库发布。

## v0.1.2（2026-11-24）

环境：Windows x64 10.0.26100，.NET SDK 10.0.404 / runtime 10.0.15，HIDMaestro 2.3.0 UMDF2。

- Windows x64 自包含单文件构建成功。
- [引擎测试](../../tests/PadHotkey.Tests/Program.cs) 20/20：触发、滞回、复位、作用域、共享按键、断连和输出失败。
- [API 检查](../../tests/api_smoke.py) 17/17：认证、配置校验、修订检查、持久化及运行状态管理。
- [配置生命周期](../../tests/profile_lifecycle.py) 9/9：首次空配置、显式导入、重启保留、清空不恢复预设及启动启用映射。
- [正常退出检查](../../tests/shutdown_smoke.py) 3/3：dry-run 限时服务和 SSE 正常结束；不证明硬件释放或强制结束进程的行为。
- CLI 启动、改键回读、暂停、限时诊断、恢复和退出通过，包含带空格的数据路径。
- 真实 HID F13 按下/释放被 Windows 观察到，结束无指定测试键残留。

## 限制

实体手柄到目标应用的端到端流程、语音输入效果、非 US 布局、跨账户及管理员目标应用未验证。历史 RightAlt 测试混入额外注入释放事件，严格序列检查失败，来源未定位；不能把发键成功视为应用功能成功。强制终止进程后的释放行为未验证。
