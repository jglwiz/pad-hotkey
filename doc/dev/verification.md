# v0.1 验证记录

验证日期：2026-11-23。本机 Windows x64 10.0.26100，.NET SDK 10.0.404 / runtime 10.0.15，已有 HIDMaestro 2.3.0 UMDF2 驱动。安装记录见 [C# 开发环境](../../../app/dotnet.md)。

## 已通过

- Release build 与 publish 成功，最终构建零警告、零错误。产物 `local/publish/PadHotkey.exe`；普通框架依赖发布，非 Native AOT。
- [引擎测试](../../tests/PadHotkey.Tests/Program.cs)：20/20。覆盖首次按住、单次触发、100ms 组合键阶段、滞回、原始轴复位、方向切换取消旧动作、作用域、热更新、共享修饰键、断连和输出失败等。按旧配置迁移的右摇杆方向有合成输入测试，不等于实际手柄已验证。
- [API 测试](../../tests/api_smoke.py)：最终发布版 17/17。检查认证、拒绝 Origin、空运行状态拒绝、配置校验、修订号、持久化、暂停恢复、限时诊断、释放与事件游标。结束时恢复测试前配置并暂停。
- [退出测试](../../tests/shutdown_smoke.py)：3/3。dry-run 中启动 12 秒长按和 SSE，再由 --seconds 5 结束；进程 5.375 秒退出、SSE 5.344 秒结束。不能据此断言真实强制退出会释放按键。
- CLI 实测 B 在 RightAlt hold 与 LeftCtrl+F10 tap 之间更新、回读和修订递增；已恢复 RightAlt。API stop 可正常结束进程。
- HID 模式成功创建真实虚拟键盘，status 检测到 XInput 索引 0 连接。有限时 Windows 钩子测试捕获 F13 按下/释放，以及两次左 Ctrl→F10→释放 F10→释放 Ctrl 的顺序；事件未标注 injected，最终无指定测试键残留。

## 未通过或未覆盖

- 右 Alt 7 秒长按时，钩子记录到非注入的按下和最终释放，同时混入额外 injected key-up；严格序列测试失败。随后 1 秒测试仍混入注入事件。来源尚未定位，不应擅自归因于工具、豆包或远程控制软件。
- 记事本可编辑区获得焦点后，右 Alt 与左 Ctrl+F10 测试截图均未见豆包语音浮层，记事本保持空白。本轮没有确认目标应用语音链路成功；没有保存语音内容。第二次 Ctrl+F10 测试已执行，但不可仅凭发送次数认定豆包内部录音状态。
- 未操作实体手柄按钮/摇杆，未验证真实方向、90% 机械行程、T3 操作效果或 USB 断连过程。历史 Python 原型的语音成功不计入本次版本结果。
- 未测试进程被强制杀死时驱动清理、跨账户访问、管理员目标应用和非 US 键盘布局。
- 未实现托盘、完整 OpenAPI、多配置自动切换与 Native AOT；没有添加自动启动项。

## 资源采样与收尾状态

HID 模式，暂停映射但持续读取连接的手柄，10.027 秒采样：主进程工作集 121.4 MiB，私有内存 72.1 MiB，CPU 消耗约单核心 0.94%。这是一次本机采样，未归属统计共享 WUDFHost 的增量成本；不是完整系统开销，也不能与其他工具直接比较。发布目录含本地 SDK 和许可证约 31.81 MB，不含系统 .NET 运行时和已安装驱动。

测试服务均已停止，AntiMicroX 保持关闭。本地证据保存在忽略的 `tasks/v1/`；测试配置分别在 `local/api-test*`、`local/hid-test`。最后通过 `start.ps1 -DryRun` 和 `padhotkey.ps1` 验证实际启动入口，在 `%LOCALAPPDATA%\PadHotkey` 建立用户数据并完成 B 键往返改键、恢复 RightAlt 与 stop；默认配置修订为 3。源码、配置、文档已完成；豆包和手柄端到端仍需后续验证。
